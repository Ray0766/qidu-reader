栖读 0.2.0-preview.2 · Windows 兼容预览版

本预览目标：Windows 7 SP1、Windows 8.1、Windows 10、Windows 11。
提供 x64 和 x86 程序。ARM 设备和 Windows 7 未安装 SP1 的系统不在本次范围。
旧系统实测尚未完成；在对应设备验证前，不保证能在每台旧电脑运行。
本机验证平台是 Windows 11 和 .NET Framework 4.8.1，不能代替 Windows 7/8.1 的实测。

安装版：双击 Qidu-0.2.0-preview.2-Compatibility-Setup.exe，跟随向导安装。
安装器自动选择 32 位或 64 位程序。缺少 .NET Framework 4.8 时会打开包内的微软官方离线安装器。
运行组件安装需要管理员授权，许可条款请本人阅读确认；若提示重启，请保存工作并自行重启后重开栖读安装包。
未修改系统安全设置。旧系统可能还需通过 Windows Update 安装微软要求的系统补丁。
栖读本身的 GitHub/本地安装包尚未购买代码签名，因此系统仍可能显示“未知发布者”。

便携版：选择与系统匹配的 x64 或 x86 ZIP，完整解压后打开 TxtReader.exe。
便携版需要电脑已有 .NET Framework 4.8 或更高的 4.x 版本，不需要 .NET 10 SDK。
缺少运行组件时，推荐改用上面的完整安装版，或从微软官方下载：
https://dotnet.microsoft.com/download/dotnet-framework/net48

安装位置与现有 0.1.9 分开，开始菜单显示“栖读 · 兼容预览”。
本版和 0.1.9 共用 %USERPROFILE%\QiduLibrary 书库，可接续书签、阅读位置和设置。
使用前先正常关闭其他栖读窗口；程序会阻止同时打开两个日常阅读窗口。
首次试用前，建议正常关闭阅读器后备份完整 QiduLibrary 文件夹。
卸载兼容预览只移除程序，不删除书库，也不卸载系统运行组件。
本版没有修改已发布的 0.1.9 或正在审核的商店安装包。
0.1.9 不支持 EPUB；回到旧版后，请使用预览版打开 EPUB，原有 TXT 可继续在旧版阅读。
同一发布页提供 SHA256-0.2.0-preview.2.txt，包含安装包和说明文件的校验值。
Windows 可在终端运行 certutil -hashfile "下载文件的完整路径" SHA256，对照校验文件。

阅读：导入本地 TXT 或 EPUB，或点击“先读示例”。支持单页、双页、滚动，字号、字体、背景和阅读宽度可调。
EPUB 2/3 可重排小说支持书内目录、封面、JPEG/PNG/GIF/BMP 插图，并使用栖读排版。
原书复杂 CSS、固定版式、音视频和受保护正文暂未支持；不联网读取远程图片。
正文按住左右拖动即可翻页；松手按距离翻页或回弹。点击正文左右侧、方向键和 PageUp/PageDown 也能翻页。
Esc 可取消拖页，Ctrl+B 显示/隐藏目录，Ctrl+F 搜索，Ctrl+D 加书签，F11 全屏。
进度保存的是原文位置；调整字号、切换模式后页码会变化，但当前阅读内容应仍可见。
书架、全文搜索、书签与旧版相同。单文件上限 150 MiB；32 位进程受可用内存限制，更建议使用 x64。

这是离线 TXT / EPUB 阅读器，不提供小说下载、账号或云同步。手机版已停止开发。
