# 栖读 0.1.9

栖读是离线使用的 Windows 中文 TXT 小说阅读器。支持书本式书架、单页／双页／滚动、纸页拖动、全文搜索、书签和自由排版，使用 MIT 开源许可。

## 下载

- **普通安装**：`TXT-Reader-0.1.9-Setup-x64.exe`，双击安装，从桌面或开始菜单打开“栖读”。
- **免安装**：`TxtReader-0.1.9-win-x64.zip`，解压整个文件夹后运行 `TxtReader.exe`。
- **文件校验**：`SHA256-0.1.9.txt`。

系统要求：Windows 11 x64。安装包已包含 .NET 运行环境，无需安装 SDK、Git 或编译源码。GitHub 自动生成的 Source code ZIP 面向开发者。

当前 GitHub 直装 EXE 尚未代码签名，Windows 可能出现未知发布者或信誉提示。Microsoft Store 申请已提交认证，正式商店下载验收尚待完成；商店版与 GitHub 直装包的签名状态不同。

## 从旧试用版升级

1. 正常关闭旧版阅读器。
2. 运行新版安装程序，保留原安装位置。
3. 首次打开时自动复制并校验旧书库，随后从原文位置继续阅读。原书库不会删除。

0.1.9 的数据位于 `%USERPROFILE%\QiduLibrary`，包括书架、书签、进度、设置和导入的文件副本。已有新书库时优先使用新库，不会用旧进度覆盖新进度。卸载程序保留独立书库。备份前先正常关闭应用，再复制整个书库文件夹。

## 验证与限制

阅读回归 1,199 项通过；独立 MSIX 的首次使用、关闭重开、覆盖升级、卸载重装及干净 Windows 安装已验证。日常 0.1.5 → 0.1.9 更新中，书架、书签、全部原文位置和排版偏好保持一致。

重排会改变页边界，保证的是同一段原文仍然可见。章节另起新页依赖标题识别。单文件最大 150 MiB；暂未提供云同步、内置备份恢复、ARM64 和直装版自动更新。

问题反馈时请说明版本、Windows 缩放、阅读模式与复现步骤，不要上传私人书库或整本版权小说。
