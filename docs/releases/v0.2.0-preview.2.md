## 系统要求与安装提示

**Windows：**目标为 Windows 7 SP1、8.1、10、11，提供 x64／x86 构建。旧 Windows 实机验证尚未完成，目前通过的是 Windows 11 + .NET Framework 4.8.1 的检查。安装版包含微软官方 .NET Framework 4.8 离线安装器；需要补装运行组件时，须本人接受微软许可和系统授权，可能需要重启。便携版要求电脑已有 Framework 4.8 或更高的 4.x 版本。不需要 .NET 10 SDK。GitHub EXE 尚未代码签名，Windows 可能提示“未知发布者”。

**Mac：**要求苹果 M 系列芯片、macOS 15 或以上，内置运行环境，无需另装 .NET 或开发工具。包已通过本地开发签名检查，**尚无 Apple Developer ID 签名和公证**，首次下载后打开可能被系统拦截，需要本人根据 macOS 安全提示确认。不提供 Intel Mac、Linux、Windows ARM64 或手机版。

## 书库、升级与返回正式版

Windows 兼容预览使用独立的安装目录、开始菜单项和卸载项，与 0.1.9 共用 `%USERPROFILE%\QiduLibrary`，以接续原有书架、书签、进度和偏好。首次试用前正常关闭阅读器，复制整个书库文件夹作备份；不要同时运行新旧版本。卸载兼容预览不会删除该书库。

0.1.9 不能读取 EPUB。返回 0.1.9 后可继续阅读 TXT，EPUB 请用预览版打开。

Mac 书库位于 `~/Library/Application Support/Qidu`。升级前退出栖读，再替换 `.app`；移走应用不会删除书库。两种系统各自保存数据，目前没有跨设备同步或跨系统书库导入界面。

## 验证与已知限制

- Windows 兼容 x64 的 1,231 项、x86 的 1,190 项阅读检查通过；独立测试安装包的安装、覆盖安装、卸载重装及从 0.1.9 样例书库接续均通过。
- Mac 在 macOS 15.7.9 / arm64 原生环境通过 53 项阅读和 3 项新进程续读检查，并从最终 app 再次验证续读。[原生验证记录](https://github.com/Ray0766/qidu-reader/actions/runs/40180313112)。
- 已检查切换单页／双页／滚动、调整字号和关闭重开后的原文锚点保留。页码会随排版变化，保存的是原文位置。
- 仍待验证：Windows 7／8.1 真实设备、缺少 Framework 的旧系统安装路径；兼容构建新一轮真实窗口失焦／最小化中断检查；用户 Mac 上的 Finder 首次打开、文件选择器和触控板操作。
- EPUB 支持无 DRM 的可重排正文、目录、封面和常见位图插图。采用栖读自己的排版，不保证复杂 CSS、内嵌字体、SVG、音视频和交互内容还原；不支持固定版式或加密正文。
- Mac 翻页采用跨平台曲面近似，视觉效果与 Windows 有差异；Windows 的手动编码重解释、搜索返回原位等细节尚未全部移植。
