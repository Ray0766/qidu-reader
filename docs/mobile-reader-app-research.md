# 移动阅读应用调研与 Windows TXT 阅读器改进建议

调研日期：2026-10-25。面向本项目的产品设计与后续开发，重点对照用户常用的夸克小说、QQ 阅读，并补充微信读书、掌阅、番茄小说、静读天下、ReadEra；华为阅读作为翻页交互的专项参考。

建议保持“本地中文小说、可靠续读、实体书观感”的定位。优先吸收常用设置就近操作、稳定的阅读习惯、可整理的书架和可取消的翻页手势。页角拖拽已由用户明确要求加入；其他新增功能按下文优先级建议推进，不自动扩大当前开发范围。

## 调研范围与依据

本次核对开发者官网、官方帮助、开发者在应用商店发布的介绍及更新记录，并观察 QQ 阅读官方展示图。属于公开资料调研，未在手机上安装逐款操作，因此不对实际跟手延迟、动画质量、续读准确率或耗电进行排名。应用商店展示图也不等于用户当前安装版本的界面。

用户对夸克的具体入口记忆不确定。本报告以官方可确认的“夸克 App 内小说服务”为对照对象；不把下载站标作“夸克小说”的包另算一种官方独立产品。当前夸克商店介绍明确包含小说阅读和朗读功能。[夸克官方商店页](https://apps.apple.com/cn/app/id1160172628)

本报告形成于 0.1.1 阶段，下文的现状与建议保留当时背景；最新实现以 [发布验证说明](validation.md)和实际代码为准。早期的[功能总览](reader-feature-research.md)保留作背景。本报告中的“建议”是针对 Windows TXT 场景的设计判断。

## 夸克和 QQ 阅读的重点借鉴

### 夸克小说的阅读现场设置

夸克官方教程把设置入口放在阅读过程中，包含字体、背景和翻页选择。其价值在于读者可以边看实际正文边调整。将这种操作方式迁移到桌面，建议让「排版」打开靠右的非模态面板，调整后立即看到真实小说，关闭后仍停在同一原文位置。[夸克排版说明](https://www.quark.cn/article009)、[设置入口说明](https://www.quark.cn/article010)

本项目的具体改进建议：

- 常用层只放字体、字号、背景、行距、阅读宽度、单／双页和翻页效果。当前已有的大多数选项继续保留，行距作为新增项。
- 将翻页方式配成短预览，直接展示“纸页翻动”和“平移”的区别，文字名称继续可见。
- 显示当前选中项；提供恢复默认值。自定义参数放在展开区，避免一个面板塞满控制项。
- 调整后不退出正文，不重置目录选择，不改变原文锚点。切换背景不应重做没有必要的分页。

夸克官网把部分免广告和离线缓存权益放在会员描述中。因此“界面清爽”的宣传不能扩展成所有入口永久无广告的结论。本项目的本地阅读流程可直接保持无广告、无需登录。[夸克会员与缓存说明](https://www.quark.cn/article010)

### QQ 阅读的便捷操作与阅读层次

QQ 阅读官方展示图中，章节标题与正文有明确层次，阅读页保留紧凑的工具入口。更新记录中的音量键翻页及小播放器收起，体现了给高频操作提供替代入口的方向。这些可以借鉴为桌面快捷键、鼠标操作和按需收起的工具区。[官方展示与更新记录](https://apps.apple.com/cn/app/id487608658)

本项目的具体改进建议：

- 正文、章节标题、工具文字维持不同的字级和留白；纸纹和书缝保持低对比度，以连续阅读为准。
- 底部保留明确的前后页按钮；键盘、滚轮、页角拖动调用同一套翻页逻辑，保证到达相同内容。
- 书签增加可见按钮并显示当前页状态，保留 Ctrl+D，降低记忆快捷键的负担。
- 隐藏工具栏后仍提供明确的唤出方式；不要把首次使用必须知道的操作全藏进手势。
- 目录定位当前章节；查人名或跳到书签后，保留「返回原位置」。这项目前已经具备，应作为回归项保留。

QQ 阅读当前公开介绍并未充分说明用户所用版本的页角拖动轨迹、松手判定和本地 TXT 排版细节。本项目的拖拽参数按后文定义，后续用真实小说验证，不把它们写成 QQ 阅读的既有实现。

## 从其他应用提炼的改进

### 排版设置要有默认值和逐书例外

微信读书对导入书的逐书字号设置说明，印证了不同书籍可能需要不同排版选择。本项目已经逐书保存字号和阅读模式，字体、主题、宽度等仍是全局设置。建议以后增加「本书单独设置」和「恢复全局设置」，默认沿用全局，只有用户明确调整时才保存覆盖值。[微信读书 10.2.2 更新记录](https://apps.apple.com/cn/app/id952059546)

静读天下提供的断行整理、缩进和空行控制，适合处理来源不一的 TXT。若引入，应保存原文，只改变展示；规范化后的内容与原文位置仍须可映射。先提供保守的默认值，再让用户选择是否整理。[静读天下功能说明](https://moondownload.com/chinese.html)

### 书架既要像书也要好找

掌阅的自定义封面和 ReadEra 的分组整理提供了两个互补方向：书籍能够被辨认，书多了仍然能够被找到。[掌阅](https://apps.apple.com/cn/app/id463150061)、[ReadEra](https://readera.org/)

对当前层架式书架，建议按下面的顺序补充：

1. 保留本地生成的布面封面、书脊和纸边；允许选择本地图片作为封面，保留恢复默认封面的入口。
2. 在封面附近展示读到的章节、进度和最近阅读时间；点击书仍直接续读，整理操作放在右键菜单。
3. 加入未读／在读／已读、分组与排序，搜索覆盖书名和用户填写的作者。TXT 没有可靠作者元数据时允许留空。
4. 书库变大后增加紧凑列表作为可选视图，默认继续使用用户要求的实体层架。

层架装饰不应压缩书名、让封面只剩难辨认的书脊，或导致窄窗口下大量空白。首屏优先展示正在读和最近读过的书。

### 听书和社交可以后置

番茄的多角色朗读、微信读书的笔记与讨论，分别服务于听读和交流场景；这些能力并非完成本地 TXT 阅读的前提。[番茄介绍](https://apps.apple.com/cn/app/id1468454200)、[微信读书介绍](https://apps.apple.com/cn/app/id952059546)

建议优先完善书签、搜索返回和数据备份，再评估基础 TTS。若加入朗读，先解决“从当前句开始、停止后回到对应原文、切换阅读方式仍能续读”，之后再考虑音色和睡眠定时。书城、排行榜、奖励任务、短剧和社区暂不进入当前首版计划。

## 页角拖动翻页的设计结论

用户要求的是一个可以随时改变方向、可以放弃的阅读动作。按下后播放固定动画无法满足这个要求。纸面的弯曲方向应受鼠标横纵位置共同影响，鼠标暂停时纸页也应暂停，往回拖时弯曲随之展开。

明确的产品行为如下，参数属于本项目初始设计值：

| 动作 | 预期行为 |
| --- | --- |
| 按住右侧上／下页角向左拖 | 预览下一页；双页模式掀起右页，露出下一组右页，纸背为下一组左页 |
| 按住左侧上／下页角向右拖 | 预览上一页，内容与正向动作互为逆过程 |
| 斜向拖动或停住 | 折线、卷曲和阴影随鼠标改变；停住后保持当前形状 |
| 松手未达到一半行程 | 沿当前弯曲状态平滑回弹，原文位置和进度不变 |
| 松手达到一半行程 | 平滑完成一次翻页，落页后提交新进度；双页前进一组两页 |
| 先拖过一半再拉回 | 以松手时的距离为准；回到阈值以内就回弹 |
| Esc、失去鼠标捕获、切换应用或改变版式 | 取消预览，保留原位置；版式变更在取消后执行 |

保留平移、淡入淡出、无动效和滚动模式。官方资料能确认多种翻页选择在市场中存在，但不能据此推断某款应用采用相同的拖拽算法或阈值。[华为阅读模式说明](https://consumer.huawei.com/cn/support/content/zh-cn16029840/)、[静读天下](https://moondownload.com/chinese.html)

完整的方向规则、提交时机、异常处理和验收用例见 [页角拖动翻页规格](page-corner-drag-spec.md)。

## 当前版本与改进顺序

0.1.1 已完成书架、搜索、书签、单／双页与滚动、字体背景宽度、章节起页和点击触发的纸页效果。已通过的 464 项检查属于这个早期版本，当时尚未覆盖拖拽；“换模式和字号后同一原文可见”继续作为后续改动的基本约束。后续实现见 [发布验证说明](validation.md)。

| 顺序 | 改进项 | 当前差距与验收重点 |
| --- | --- | --- |
| 本轮已明确的下一项开发 | 页角拖动、跟手弯曲、完成／回弹 | 当前只有自动播放动画；新增预览状态和原子提交，正反向、书首尾、跨章节及内容分段均验证 |
| 建议紧随其后 | 阅读设置面板与书签入口 | 当前是模态排版窗口；改为不遮挡主要正文的现场预览，补行距、重置和可见书签按钮 |
| 建议随后补齐 | 数据备份与恢复 | 属于早期首版目标但尚未实现；备份要同时包含书籍、进度、书签和排版偏好 |
| 书架进一步完善 | 封面图片、阅读状态、分组和排序 | 当前有书本外观、筛选、改名和移出；新增管理不改变书籍标识及续读记录 |
| 排版进一步完善 | 逐书覆盖、自定义目录规则、可选断行整理 | 不修改原文件，旧书签与原文位置继续有效 |
| 后续评估 | 基础听书、笔记导出、阅读统计、可选同步 | 按实际使用频率独立设计，不影响离线阅读与本地数据所有权 |

## 后续手机体验核验

如需把交互进一步对齐用户熟悉的手机版本，核验应记录手机系统、App 版本、具体书籍来源和阅读设置。用相同动作比较进入阅读、调字号、添加书签、搜人名后返回、慢拖／回拖／松手、关闭重开六条路径。在线精排书与导入 TXT 分开记录。

本次公开资料足以确定功能借鉴方向。真正的跟手效果应在本项目中以录屏、实际鼠标操作和原文位置断言验收，不能仅由一张翻页中间图判定完成。
