栖读 0.1.9 预览版

商店版通过 Microsoft Store 安装；是否可下载以商店页面为准。
支持 Windows 11 x64，自带 .NET 运行环境，无需另装 SDK 或编译。
安装后从开始菜单打开栖读。
便携版：解压 ZIP 后双击 TxtReader.exe，请保留整个文件夹。

书架
  导入 TXT / Ctrl+O / 把文件拖入窗口，支持多选。
  点击层架上的书本阅读。可筛选书名、改名、移出。
  移出会保留本机副本、进度与书签，重新导入可恢复。
  空书架可直接导入或试读示例；筛选无结果时可清除筛选。

阅读
  当前章节在目录中自动高亮并滚入可见范围，重新展开目录也能定位。
  顶部选择单页、双页、滚动；双页先左后右，一次翻两页。
  单页、双页均按识别出的章节另起新页。
  正文任意高度均可单击：左半边上一页，右半边下一页。
  ← / → 或 PgUp / PgDn 也可翻页；选过目录或书签后左右键仍可用。
  A− / A+ 调整字号，范围 14–36。
  「排版」选择字体、背景、纸张质感、宽度和翻页动效。
  动效：纸页翻动 / 平移 / 淡入淡出 / 无动效。
  系统关闭动画时不播放卷曲，仍可左右拖动翻页。
  「收起目录 / 显示目录」或 Ctrl+B，切换左侧栏。
  左侧目录、底部整书进度条均可定位。
  F11 全屏；Esc 优先取消拖页，否则退出全屏。

正文拖动
  正文任意位置按住鼠标左键，向左拖为下一页（组），向右拖为上一页（组）。
  页角、上方、中间、下方都可以，左右半边也都能向任一方向拖。
  上下移动改变弯曲，停手即可停住，也可把纸页拉回。
  水平拖出足够距离后松手完成，短拖回弹；门槛相同，不随起点改变。
  普通宽度下约拖出 180 个逻辑像素，窄页自动降低门槛。
  以松手位置为准：即使曾拖过门槛，拉回后松手仍会回弹。
  Esc、切换应用、最小化、切换模式或调整字号会取消尚未落定的拖页。
  未完成的翻页不改变已保存位置；正常落页后才更新阅读进度。

搜索与书签
  Ctrl+F 搜索整本书，每批 200 条，支持前后翻批。
  点击结果高亮定位，「返回原位置」继续原来的阅读。
  Ctrl+D 添加当前位置书签，左侧书签列表可跳转和删除。
  搜索、书签跳转后再换模式、字体、字号或宽度，原文仍可见。

翻页：正文左右半区单击、正文任意位置左右拖动、底部按钮、左右方向键、空格、PgUp/PgDn、滚轮。
滚动：鼠标滚轮、PgUp/PgDn，或底部向上读 / 向下读。

正常关闭重开恢复上次书籍、位置、阅读模式、字号。
字体、背景、宽度、单／双页、动效和侧栏偏好全局保存。
重排后页边界会变化，原句可能位于页中部或右页。
滚动条对应当前加载的正文窗口，底部进度条对应整本书。
双页遇内容分段末尾可能有一页空白，继续翻页即可接着读。

数据位置：%USERPROFILE%\QiduLibrary
books 保存导入文件副本；reading.db 保存书架、进度、书签和偏好。
未打包版首次启动可复制旧版 %LOCALAPPDATA%\TxtReaderPreview 书库，原数据保留。
商店版受 AppData 隔离影响，可能无法读取旧试用书库；首次使用可重新导入 TXT。
若先用新版未打包程序完成迁移，商店版可直接读取共享的 QiduLibrary 目录。
迁移成功后以新目录为准，不会用旧备份覆盖新的进度。应用不联网获取小说。
升级时先关闭阅读器，再运行新安装包即可；卸载程序保留本机书籍和进度。
商店候选 MSIX 尚未由微软签名，不用于直接分发；审核通过后商店负责签名和更新。

乱码时在左下角选择文件编码。自动先尝试 UTF-8，再尝试 GB18030；
Big5 和无 BOM 的 UTF-16 请手动选择。单文件最大 150 MiB。
附带小说为自有排版示例，包含重复段落。
当前尚未包含备份恢复、封面图片导入、云同步和直装版自动更新。
